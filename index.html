What this project does

Businesses send coupons to drivers on the road, but most offers get ignored. This project learns from past decisions to estimate how likely a driver is to accept an offer, so the right coupon can be shown at the right moment.

The data

The UCI in-vehicle coupon recommendation dataset. Each row is a driving scenario with a coupon offer and whether the driver accepted it.

The approach

A logistic regression model set the baseline. An XGBoost model was then trained and compared against it on a held-out test set.

The outcome

XGBoost was the best model and clearly beat the baseline on ROC-AUC, as shown below.

XGBoost beats the baseline

ROC-AUC measures how well a model ranks accepted coupons above rejected ones. A score of 0.5 is a coin flip and 1.0 is perfect.
